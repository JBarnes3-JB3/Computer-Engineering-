CprE 4500/5500 – Project 1
Remote System Monitoring using Sun RPC

Project Description: 
This project implements a **remote system monitoring application using Sun RPC. A server program runs on a host machine and provides system information upon request. Aclient program connects to the server using RPC and retrieves this information remotely.

The purpose of this project is to demonstrate:
-> Defining an RPC interface using 'rpcgen'
-> Implementing a client–server architecture with Sun RPC
-> Using autogenerated RPC stubs
-> Handling platform-specific issues on macOS

Project Files:
- `date.x` –> RPC interface definition file
- `date.h` –> Header file generated by `rpcgen`
- `date_svc.c` –> Server-side RPC stub
- `date_clnt.c` –> Client-side RPC stub 
- `server.c` –> Server implementation containing the RPC service logic
- `client.c` –> Client implementation that invokes the remote procedure
- `README.md` –> Instructions for building and running the project

Platform Information:
-> Operating System: macOS
-> Compiler: gcc (clang)
-> RPC Tool: `rpcgen` (Sun RPC)

Build Instructions:
All commands should be executed from the project directory.
Generate RPC Source Files:
For bash
-> rpcgen date.x
This command generates the following files:
-> `date.h`
-> `date_svc.c`
-> `date_clnt.c`

Compile the Server
For bash
-> gcc -o server server.c date_svc.c

Compile the Client

For bash
-> gcc -o client client.c date_clnt.c

Start the Server:

Open a terminal window and run:
For bash and macOS
-> ./server
The server should start and wait for incoming RPC requests.

Run the Client:

Open a second terminal window and run:
For bash and macOS
-> ./client localhost

Expected Output:
When the client successfully connects to the server, it will print information returned by the server, such as the current system time. Example output:
-> Current Time: Sun Feb 15 20:01:33 2026
